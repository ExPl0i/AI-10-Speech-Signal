## Звук как сигнал: спектрограмма, мел-шкала, распознавание голосовых команд

[![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ExPl0i/AI-10-Speech-Signal/blob/main/%D0%9F%D0%A0-%D0%97%D0%B2%D1%83%D0%BA%20%D0%BA%D0%B0%D0%BA%20%D1%81%D0%B8%D0%B3%D0%BD%D0%B0%D0%BB.ipynb)

Первое занятие Блока 2 Темы 2 «Применение искусственных нейронных сетей» курса «Искусственный интеллект» для 10 класса. Ученики превращают звук в картинку, понятную сверточной сети: сами пишут спектр, спектрограмму, мел-фильтры и логарифмическую мел-спектрограмму и сверяют их с `torchaudio`. Затем готовят записи (выравнивание длины, разбиение по дикторам, аугментация) и обучают сеть SimpleCNN из Темы 1 распознавать шесть голосовых команд водителя: «вперед», «стоп», «налево», «направо», «быстрее», «медленнее». Это первая часть голосового помощника, который собирается на занятии Т2.Б2.5.

## Содержимое

| Файл | Описание |

| `prepare_group.py` | Переводит записи группы с телефонов (m4a, mp3, ogg и другие) в WAV 16 000 Гц моно и раскладывает в `data/commands/<ученик>/<команда>_<номер>.wav`; нужна программа ffmpeg |

Записей голоса учеников в репозитории нет и быть не должно: это персональные данные, они хранятся только на школьном носителе.

## Теория (презентация)

1. **Звук и цифра.** Дискретизация, теорема Котельникова, частота Найквиста и наложение частот; квантование и шум квантования; формат WAV и децибелы.
2. **От звука к частотам.** Дискретное и быстрое преобразование Фурье; спектрограмма: кадры 25 мс с шагом 10 мс, окно Ханна; компромисс между точностью по времени и по частоте.
3. **Мел-шкала.** Нелинейность слуха, формула мел-шкалы, треугольные мел-фильтры, логарифмическая мел-спектрограмма; мел-кепстральные коэффициенты одной строкой.
4. **Данные и аугментация.** Записи группы и запасной набор; разбиение по дикторам; шум, сдвиг, изменение скорости, закрытие полос спектрограммы; сеть SimpleCNN на мел-спектрограмме.
5. **Практика.** Шесть заданий; ошибки распознавателя и безопасность.

## Практическая работа

| Задание | Что пишем | Главный результат |
| --- | --- | --- |
| З1 | `tone`, `spectrum`, `quantize` | пики 440 и 1000 Гц с амплитудами 0,5 и 0,3; тон 9000 Гц виден как 7000 Гц; шум квантования 97,9 / 50,4 / 25,1 дБ при 16 / 8 / 4 битах |
| З2 | `frame_signal`, `my_spectrogram` | 201 частота × 101 кадр на секунду; совпадение с `torchaudio.transforms.Spectrogram`; компромисс длины окна |
| З3 | `hz_to_mel`, `mel_to_hz`, `mel_filterbank`, `log_mel` | 1000 Гц = 999,99 мел, 8000 Гц = 2840,02 мел; совпадение с `melscale_fbanks` и `MelSpectrogram` |
| З4 | `fit_length`, `split_by_speaker`, `add_noise`, `time_shift`, `change_speed`, `mask_bands` | записи по 1 секунде; дикторы обучения и проверки не пересекаются; шум ровно с заданным отношением сигнал/шум |
| З5 | `SimpleCNN`, `train_epoch` | 25 254 параметра; точность на новых дикторах без аугментации и с ней |
| З6 | `recall_per_class`, `most_confused` | матрица ошибок, самая частая путаница, разбор ошибок на слух |

Задания повышенной сложности: поиск команды в длинной записи скользящим окном, устойчивость к шуму двигателя, мел-кепстральные коэффициенты.

**Два режима** выбираются в первой ячейке ноутбука, оба работают на процессоре. Легкий – для компьютеров аудитории: по 200 записей на команду, сеть с 8 и 16 каналами, 15 эпох. Полный – для Colab или мощного компьютера: по 800 записей на команду, сеть с 16 и 32 каналами, 25 эпох.

**Источник данных** (`DATA_SOURCE` в первой ячейке): `'группа'` – записи группы из `data/commands`, `'запасной'` – подборка Speech Commands v2 из `data/reserve`.

## Подготовка аудитории

1. На компьютере с интернетом выполнить `python prepare_data.py`: скрипт потоком читает архив Speech Commands v2 (около 2,3 ГБ) и оставляет около 160 МБ в `data/reserve`.
2. Записи группы перевести в WAV: `python prepare_group.py путь/к/записям` (в папке – подпапки учеников, имя каждого файла начинается с команды: «вперед_01.m4a»). Результат – `data/commands`, только на школьном носителе.
3. Скопировать папку `data` рядом с ноутбуком на компьютеры аудитории.

## Требования

Python 3.9 или новее, `numpy`, `torch` 2.0 или новее, `matplotlib`; для сверки – `torchaudio` той же версии, что `torch` (в Colab установлен); для `prepare_group.py` – программа ffmpeg. Видеокарта не нужна.
